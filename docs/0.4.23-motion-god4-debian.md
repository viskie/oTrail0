# oTraiL 0.4.23, GOD 4 and Debian Shell 1.0

- Smooths the normal live GPS marker and bubble between fixes, projecting short
  movement from the average of the latest five speed samples.
- Shows bubble speed and active-road distance with four decimal places; absent
  road guidance is `--`.
- Adds a white `dd--MM--yyyy HH:mm:ss` clock at the lower-left status bar.
- Removes the quadrangular background from the triangular map-theme control.
- Separates Debian from GOD. Installing Debian Shell activates it and opens its
  own UI; a symmetric nine-sided icon launches it from the map control row.
- GOD 4 adds internal-storage folder import and an SCP workspace profile, fixes
  versioned source workspaces, and publishes the current 0.4.23 build baseline.

SCP configuration is stored in GOD. The standalone Debian module supplies the
`scp` client and can sync remote files into GOD's private workspace through the
shared `/app-data` binding. Host-key and key provisioning remain explicit.
