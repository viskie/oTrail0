# 0.3.6 — compact destination headings

Destination headings, destination marker titles and turn-list titles use compact Indian state abbreviations and PIN codes: `Bijnor, Uttar Pradesh 246701, India` becomes `Bijnor: UP-246701`. The repeated country suffix is omitted. Missing state or PIN fields do not produce dangling punctuation. Original destination names and coordinates remain stored unchanged.

Retains the centered 18sp heading, landscape footer/settings layout, stop metrics and label styling from 0.3.5.
