# 0.3.0 — repeated passes, distance and road context

## Trail colors

The app keeps a fixed 31-color pass palette, viewable in Maps & downloads. Repeated traversal of the same quantized geographic edges after two minutes receives another color, including reverse traversal. Colors cycle after pass 31. Detection is an approximate 35-metre display grid, not road-network map matching; GPS offsets, parallel lanes and sparse fixes can affect matches. Green is reserved for inferred continuity. Color geometry is derived off the main thread and never edits recorded fixes.

## Distance and drive logs

The main statistics show total recorded kilometres. Selected history also shows its own trail distance. The moving/recording status includes the current drive's recorded kilometres since the most recent stop departure. Stop dots and the Stops list show distance and elapsed average speed since the previous stop, with a gap notice when coverage is incomplete. The first leg starts at the first collected fix.

Distance uses original, unthinned observations. Poor accuracy, impossible speed, long GPS gaps and stationary jitter are excluded; recorded stop intervals do not accumulate parked drift. Green inferred edges are excluded. Average speed is recorded distance divided by elapsed departure-to-arrival time; missing GPS coverage can understate it. No missing route distance is invented.

Database v2 to v3 adds only the derived stop_drive_metrics table. Existing trips, fixes, stop details and sync logs are retained. Metrics backfill all collected history, update in the background and appear as numeric properties on stop GeoJSON features. Normalized trail backups retain the source observations and stop timing; derived metrics are recomputed after restore rather than treated as independent source records. Map/routing datasets and road caches remain outside trail backups.

## Road names and landmarks

Tap a road, including a recorded trail or navigation line, to see its mapped reference/name. Cached results appear first; online refresh is attempted when not in Offline only mode, subject to request throttling. The Turns button still opens navigation instructions.

While moving, the road strip and amber markers show cached landmarks ahead along the identified road, including temples, mosques, churches, gurdwaras, other places of worship, historic sites, attractions and viewpoints. Tap the strip for a list or an amber marker for details. Source data is OpenStreetMap via Overpass; it is not an exhaustive inventory of every public landmark. Unnamed places of worship can appear under their mapped type. Attribution and fetch dates are shown where relevant.

Current-road association uses nearby mapped road geometry and matching reference/name, with a 100-metre roadside corridor and rejection of closer alternative named roads. Ahead filtering uses recent direction of travel. These are proximity estimates, not confirmation of access or opening hours. The downloaded offline basemap itself is not mined for road/POI features.

Road areas are cached in a separate phone-only SQLite database. Automatic lookup reads the cache first, refreshes missing/older-than-seven-day areas online, and limits automatic requests to one per two minutes. Explicit road taps can refresh a cached area, at most once per five seconds. Network failures retain cached content. Offline only makes no road-service requests. No map, road or POI dataset is bundled in the APK/repository.

## Validation

45 JVM tests pass, including prior navigation, updater, GPS dwell and continuity tests. New checks cover historical leg boundaries, gaps, parked jitter, overlapping legacy stops, reverse repeated passes, 31 unique non-green colors, road-ref normalization, same-road temple inclusion and parallel-road exclusion. Android lint has no errors; app and instrumentation APKs compile. Instrumentation adds a v2-to-v3 journal-preservation check and persistent road-cache reopen check. These new device checks have not run because no ADB phone is connected for this build. Existing map teardown and independent stop-detail fixes remain in place. Live Overpass retrieval and the new UI still need phone verification.

Install this update over the existing app with its unchanged signing identity. Do not uninstall to upgrade.
