# 0.3.1 — grey fullscreen theme

- Shared grey background/surfaces, blue body accents, purple headings/bold status, orange secondary labels, condensed body typography and medium-weight button labels. Primary accents are #0078FF, #BD00FF, #FF9A00, #01FF1F and #E3FF00 from https://www.color-hex.com/color-palette/33554. A darker blue text variant preserves contrast for small labels.
- Map, navigation and routing/download buttons use compact rounded controls with consistent outlines, disabled states and a yellow ripple. All buttons use the requested #8B21B8 fill with #29335C text. Native dialogs inherit the app typography and accents.
- Navigation uses coral #FF7F50. The first five trail colors are #17DEEE, #FF7F50, #FF4162, #ECF284 and #10AEB2 from https://www.color-hex.com/color-palette/5338. The remaining 26 are drawn from https://siter.io/retro-color-palette. All 31 pass colors are unique. Repeat detection now checks nearby aligned path samples within approximately 28 metres, including shifted GPS tracks and reverse traversals, rather than requiring identical grid edges. Perpendicular crossings are excluded. Light trail colors get a dark halo for visibility over basemaps.
- Preserves the user's manually chosen continuity color #00FBFF as a separate overlay; does not change pass-detection or trail geometry. Palette settings now show swatches with readable hex labels.
- Portrait and landscape hide Android system bars using immersive mode; edge swipes reveal transient system controls. App title/strapline rows are hidden. IME insets are respected when entering text.
- More map space: reduced row spacing, hidden redundant tip/legend rows, compact navigation text and controls, a single-line road strip, and a narrower landscape sidebar, and a floating Locate button on the map in both orientations. All prior actions, history, Stops, road lookup, navigation and settings remain available. Map attribution remains visible.
- No journal schema or calculation changes. A pre-update archive of databases/preferences was saved on the connected phone as files/pre-theme-backup.tar.

Validation: 47 JVM checks and lint pass. A startup regression was found on the phone and corrected by requesting fullscreen only after the decor view exists; device checks include a cold Activity launch. The metrics-migration test now compares normalized tables rather than changing snapshot creation timestamps.
