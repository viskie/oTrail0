# 0.4.2 — map icon toolbar

CAM's map icon is a regular upright pentagon, with the same visual scale and touch target as the hexagonal Locate icon. Both use the editable UiConfig palette. The top-right icon bar scrolls horizontally when future icons exceed the map width. The pentagon update was built after the phone disconnected from ADB; final shape placement is not yet device-verified.

Version code increases to 25 so phones already running the pre-publication 0.4.1 validation build receive the icon update. Module packages, activation, old versions, private data, settings and journal remain in place.
