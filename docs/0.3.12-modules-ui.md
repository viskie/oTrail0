# 0.3.12 — module planning scaffold and map UI

- `modules/` contains API v1, a catalog, view/lifecycle host, planning templates and proposed Road ahead/Journey summary specs.
- Settings → Extension modules displays the plans. No executable extension is shipped in this version. In particular, Mod1 (source editor/build tools) is proposal-only and absent from the APK.
- Future trusted bundled modules can contribute optional UI and consume immutable snapshots. Enable flags are off by default and stored in preferences. Core recording does not depend on module flags. New executable modules require a signed app update; the scaffold does not dynamically install APKs or AARs as code plugins.
- Current live drive is neon pink. When stopped, the most recent incoming drive stays pink. Older history keeps its 31-pass colors; inferred continuity remains green. Highlighting changes display strokes only, never journal rows.
- Locate logo/regular hexagon are reduced by 40%, with a beveled face. The full 56dp touch area remains.
- Centered turquoise destination heading has extra bold weight.

All UI colors and sizes remain editable through UiConfig.java. Module authoring instructions are in modules/README.md.
