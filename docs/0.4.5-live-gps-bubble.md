# 0.4.5 — live GPS bubble and mirrored navigation axis

Live status/speed moves from the side panel into one persistent map bubble above the GPS dot, followed by a divider, coordinates fixed to four decimal places, locality/road context and nearby worship distances. The bubble remains upright during map rotation. The latest automatic long-stop label is suppressed while it is displayed; other stop details/history remain available. Address lookup uses Android Geocoder and a private atomic cache. Worship lookup uses OpenStreetMap/Overpass with a bounded response, throttled online refresh and retained cache, independent of the map's offline-tile toggle. Five groups are Hindu, Muslim, Christian, Sikh and Buddhist. Distances are straight-line in any direction within 25 km; absent mapped coverage is stated explicitly. Source coverage/network availability do not guarantee a result for every religion.

Destination headings now explicitly apply bold sans-serif on each update so Bijnor remains visibly bold. Navigation/trail stroke rendering explicitly uses solid strokes, rounded caps/joins and antialiasing to avoid sharp electrical-looking spikes/gaps, without altering route/GPS coordinates or the journal.

WTF! travel now points bottom-right → top-left, retaining the magnitude of the 1/0.8 slope: vector x=-0.8, y=1 up (−38.66° from screen-up). Existing enabled mode/settings/modules, downloaded map data and recorded journal are preserved. No core database migration or tracking-service changes.
