# 0.4.21 — GOD v3 native editor and Debian shell

This release updates the current 0.4.20 app in place. Database schemas, GPS
collection, recorded coordinates, stops, maps, routing choices, modules, photos,
audio and backup formats are unchanged.

## Required one-time reinstall and data migration

0.4.21 starts a new long-lived APK signing identity. Android cannot install it
over builds signed by the previous identity. Before uninstalling the old app,
create a complete backup from oTraiL and copy/export that backup outside the
app-specific and private storage directories. Verify that the exported file is
visible from another app or computer. Uninstalling deletes Android private app
data; reinstall alone does **not** preserve it. Install 0.4.21, grant the needed
permissions, then restore the exported backup before recording new trail data.

The 0.4.21 signing key is retained for subsequent in-place updates. Keep an
independent protected copy of the release keystore and module signing key; losing
either identity would require another migration.

## GOD 3.0 editor

- Replaces GOD's plain Android `EditText` source editor with Sora Editor 0.24.7.
- Adds Java syntax highlighting from a VS Code TextMate grammar and the Darcula
  TextMate theme. Sora and TextMate resources/classes are packaged in the host APK;
  GOD remains a separately signed downloadable module.
- Uses Sora's native unlimited undo/redo and `EditorSearcher` implementation.
- Adds an always-native find/replace bar with previous, next, replace-one and
  replace-all actions. `Ctrl+F` opens the bar.
- Replaces the flat file picker with a filterable, expandable project tree.
- Adds background project-wide text search (`Ctrl+Shift+F`) with clickable
  filename/line results. It skips generated folders, release archives, binary
  files and files over 500 KB, and caps displayed matches at 500.
- Existing tabs, atomic drafts, saved-file backups, source snapshots, compiler
  logs and build/publish screens remain available.

## Debian shell

- Adds an ARM64 static PRoot 5.5 executable to the host APK and a GOD Shell tab.
- Downloads and SHA-256 verifies a pinned Debian Bookworm ARM64 rootfs on first use.
- Safely extracts tar/XZ entries with traversal, entry-count and expanded-size
  limits; preserves links/modes and writes working DNS configuration.
- Starts a PTY-backed login shell through Debian `script`, with streamed output,
  command input, Ctrl-C, Tab and history-key controls.
- Typing `exit`, tapping **Exit shell**, closing GOD or a failed process terminates
  only the shell and returns to the app UI. Tracking continues independently.
- Explicit guest bindings expose the selected project, GOD data and oTraiL's own
  app directories. Other apps' private directories remain inaccessible.
- App-specific external storage is always available. Shared storage is mounted only
  after the user enables Android's special all-files access setting.

The fake root user exists only inside PRoot. It is not Android root. Commands can
modify or delete oTraiL's journal, keys and module data through `/app-data`, so the
launch flow shows a destructive-access warning. The all-files permission is
store-restricted and is never silently granted.

## Trail rendering rollback

Only the 0.4.20 screen-space lane/ribbon trail drawing algorithm is reverted.
Recorded and reconstructed trails again use the previous rounded osmdroid polyline
renderer with their existing colour and live/history outlines. The lane allocator,
custom Canvas overlay and their display-only configuration/test are removed.

No GPS row, trip, stop, inferred gap, metric, palette assignment or database value is
changed. Route options, larger map labels, raster scaling and Resonations audio from
0.4.20 remain intact.

## Packaging and validation

- App version: 0.4.21, versionCode 44.
- GOD module: 3.0.0, requiring host versionCode 44 and Android 15 for the existing
  GOD compiler workflow.
- Sora/TextMate are LGPL-2.1-or-later; their license and grammar/theme source notices
  are included in the APK assets.
- PRoot is GPL-2.0 and its license/provenance are included.
- The Debian rootfs is downloaded, not bundled in the APK.

Host JVM tests, Android lint, app/instrumentation APK assembly, GOD Java compilation
and single-DEX conversion must pass before release. PRoot/ptrace, terminal input,
special shared-storage access and touch editor behavior still require an ARM64 phone.
