# 0.4.8 — calmer map and 13-second GPS

The foreground GPS recorder requests one unbatched fix every 13 seconds. Android 12+ explicitly requests HIGH_ACCURACY from the satellite GPS provider; Android 11 retains its direct GPS provider fallback. Existing freshness/accuracy checks and uncertain-stop recovery remain intact. Requesting high accuracy cannot improve satellite reception by itself.

Map polling follows the 13-second cadence; download progress still polls every 2.5 seconds. The redraw key uses GPS/status flags instead of the formatted elapsed stop duration, preventing minute changes alone from rebuilding overlays and reopening popups. The persistent GPS bubble avoids resetting unchanged text. Stop timers still derive from the stored arrival timestamp.

GPS and navigation boxes use a shared 12.8dp rounded corner (0.8 × 16dp). Their text increases by 1sp; the GPS bubble remains compact. Nearby data is titled “Religious places nearby”; provider/cache identifiers remain compatible. Police stations remain in the same list. Decorative lower-right orange gradient becomes brighter through GRADIENT_BRIGHT_ORANGE and a stronger canvas endpoint blend, preserving manually edited base colors.

No journal, preferences, modules, downloads or photo migrations. This update installs over the existing package with the same signing certificate.

Validation: 91 JVM tests passed, including 13-second sampling across poor reception without resetting stop arrival. APK signature matches the existing app. ADB is disconnected; this version has not been checked on the phone.
