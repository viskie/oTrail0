# 0.3.4 — vibrant finish over the manual palette

Keeps the current manually selected cyan button fill, magenta button/city text, coral headings, grey background, all font families/sizes and all trail/location-dot colors. Adds cyan-to-blue button gradients, a magenta lower edge, bold button labels, tinted panel gradients and saturated accent borders. Status, map selection, road context and navigation now have distinct colored surfaces; settings cards cycle through the configured cyan, purple, orange, lime and pink accents. The grey canvas gets a light cyan/magenta tint. Toggle thumb/track colors match the palette.

All finish controls live in UiConfig.java: VIBRANT_FINISH, BUTTON_GRADIENT_ACCENT, BUTTON_GRADIENT_MIX, BUTTON_EDGE_ACCENT, BUTTON_FONT_STYLE, PANEL_TINT_MIX and PANEL_ACCENTS. Set VIBRANT_FINISH=false for flat controls/surfaces. Existing base values were retained rather than reset to an earlier theme. Panel decoration preserves view padding and the existing compact map layout and 44dp button targets.

No changes to GPS collection, stop detection/reconciliation, journal schema, downloaded data, route engines or trail geometry. Existing map typography/trail palette overrides remain in effect. Existing conditional statements were braced to satisfy lint, without changing their behavior.

Validation: 52 JVM checks pass; final APK build and lint pass. The phone was not visible over USB or Wi-Fi ADB, so installation and device visual checks could not be performed for this version.
