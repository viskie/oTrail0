# 0.4.13 — centered audio title, compact labels and icon glow

Resonations title is horizontally centered. Its filename text uses the dedicated 11sp RESONATIONS_TEXT_SP token (previously NAV_SUMMARY_SIZE_SP at 12sp); heading and button typography remain unchanged. The destination panel's instruction bottom padding and summary top padding are zero, removing the extra gap between lines two and three.

Floating map statistics gain exactly one physical pixel of text size, with padded ` || ` delimiters separating the existing concepts. TOTAL_STATS_EXTRA_PX and TOTAL_STATS_DELIMITER are editable in UiConfig. The strip stays single-line and horizontally scrollable.

NeonBorderDrawable provides a shared shape-following glow for the menu, octagonal WTF toggle, pentagonal camera and hexagonal Locate controls. Each retains its existing border color, shape, glyph, visual scale and touch target. Masks stay solid, and the glow has space inside each full-size target. Existing panel glows are unchanged. No data or tracking migrations.
