# 0.4.3 — WTF! map camera

The base app adds a persistent `!` toggle to the map's top-right icon bar, independent of installed modules. Enabled uses purple/cyan; disabled uses black/grey. The live GPS dot stays at the map center. Map dragging cannot detach the camera; zoom remains available. Existing navigation route/turn guidance continues without route-preview fitting taking the camera away from the GPS dot. No destination is invented or navigation started without an existing route.

Travel direction is held toward the upper-right along the exact screen vector `(0.8 right, 1 up)`: slope y/x = 1/0.8 and 38.6598° clockwise from screen-up. The conceptual −20° example is not used. The map rotates about the centered dot using `rotation = diagonal bearing − true GPS course`, with short-arc animation. A screen-space north arrow shows true north as it rotates. GPS course is relative to true north, not a magnetic sensor.

Heading changes require a recent moving fix, speed ≥1.5 m/s and accuracy ≤35 m, and are suppressed during an uncertain signal or a confirmed stop. When recorded GPS course is unavailable, displacement is used only within one minute and beyond combined position uncertainty; otherwise the last reliable orientation is held. Mode, heading and zoom survive activity/app restarts. History temporarily suspends the camera and uses north-up; enabling `!` there returns to live tracking. Disabling restores north-up and free map panning.

Colors, label, typography, diagonal, accuracy/speed limits and turn duration are editable under `WTF_*` in UiConfig.java. No database migration, recorded-fix filtering, journal deletion, collector interval or module-data changes. Existing map providers share the same camera behavior. Android device validation is pending because no phone is currently visible to ADB.

Validation: assembleDebug, testDebugUnitTest (78 tests, zero failures) and lintDebug pass. Geometry tests verify the 1/0.8 slope for courses around the compass, short turns crossing north, and rejection of stopped/stale/weak/noisy/gapped observations. Device/on-road camera validation remains pending.
