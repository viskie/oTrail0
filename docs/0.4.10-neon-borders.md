# 0.4.10 — reusable neon borders

NeonBorderDrawable extracts the manually added recessed button border into a standalone Drawable. Its palettes are CURRENT (the existing turquoise stops), LIME, BRIGHT_ORANGE, and BRIGHT_YELLOW. Each view gets an independent drawable. Buttons retain their manually edited typography, sizing, padding, text/ripple colors and turquoise glow; only the innermost top lip gains a brighter thin reflection so it no longer fades into black.

NavigationControls' destination/Bijnor box uses LIME, ResonationsWidget uses BRIGHT_ORANGE, and GpsBubble above the GPS dot uses BRIGHT_YELLOW. The destination and GPS boxes retain the configured corner radius. Panels use shallow edge insets rather than the button's pill shape. Existing content padding and text colors are retained.

UiConfig holds NEON_CURRENT, NEON_CURRENT_STOPS, NEON_LIME, NEON_BRIGHT_ORANGE, NEON_BRIGHT_YELLOW, NEON_INTERIOR, NEON_CURRENT_REFLECTION, NEON_INNER_TOP_ALPHA and NEON_INNER_TOP_WIDTH_DP. Shader creation happens when bounds change, with correct nonzero bounds handling, drawable alpha and color filtering. The manual menu/swatch sizing and Resonations edits are preserved. The generated android-project-sources.txt is left untouched.

No journal, tracking, playback, navigation, preference or download migrations.
