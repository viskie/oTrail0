# oTraiL 0.4.22 and GOD 3.2

oTraiL 0.4.22 changes only the signed extension host ceiling from 20 MB to
240 MB. It retains the 0.4.21 signing identity and installs in place.

GOD 3.2 fixes blank file opening by binding the visible Sora editor to its real
file path. Its Editor displays an expandable/filterable project tree, enters a
full-screen workspace for opened files, provides a floating return-to-GOD button
and supports Ctrl+S, Ctrl+Shift+S, Ctrl+Z/Y, Ctrl+F, Ctrl+Shift+F, Ctrl+W and Esc.

The 95 MB checksum-pinned Debian Bookworm ARM64 rootfs is stored inside the GOD
module. **Install / repair included Debian** verifies and expands it locally; it
does not download Debian again. Extracted storage is additional to the module
download. Type `exit` to return from the shell to GOD.
