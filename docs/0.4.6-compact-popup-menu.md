# 0.4.6 — compact GPS popup and left navigation

The GPS popup has zero padding, a uniform configurable 11sp font, content-sized width up to 260dp, no empty rows, and only available locality/road/worship values. Lookup failures, pending requests, missing categories and source/distance notes appear in the restored black/cyan side-panel notes box. Only the destination place name is bold; the colon/state/PIN remain regular.

A subtle white smile is drawn inside the existing GPS dot only for fresh live fixes with accuracy ≤15 m and no uncertain-signal flag. It does not move, animate or resize the dot and is absent for stale/weak fixes, saved stops and history.

Tracker, Places, Stops, History/Live and Settings move into a collapsible drawer opened by the floating top-left menu icon. The drawer reuses the right panel's editable gradient shading. Close, outside tap and Back dismiss it. Existing actions retain their behavior; recorder state is unaffected. The top-right icon bar reserves room for the left menu trigger.

Existing journal, module versions/settings/data and phone-only downloads are retained. No core schema or service changes.
