# 0.4.0 — downloadable GOD module host

The app adds a signed GitHub module/version catalog, `.oTrail0` package loading, password-gated download/installation, activation/deactivation and rollback. GOD is downloaded separately; its executable classes and compiler/publisher libraries are absent from the APK.

GOD provides Project / Editor / Build / APKs / Tools screens inside oTraiL. Toolchains are independently downloadable and selectable signed catalog entries. The initial engine performs offline app-Java → DEX → aligned signed APK builds, retaining verified resources/native libraries and rejecting unsupported resource/build-system changes. No Termux, shell, external app or server is used.

The editor supports file tabs, undo/redo, search, syntax highlighting and persisted drafts. Saves keep backups; builds take source snapshots. APK signing requires the existing PKCS12 key/certificate; incompatible builds cannot replace the installed app. Module files and source workspaces do not modify trail storage.

GOD generates a non-exportable Android Keystore SSH key. The user exports only its public key, registers it with GitHub, then configures/tests repository access. A build can be committed with a unique filename under releases/ plus a checksum sidecar, without a remote force push or GitHub Releases workflow.

The editor uses the :modules process and compiler the :compiler process, separate from the existing GPS recorder. Main APK updates continue through the existing daily/manual GitHub updater and Android's install confirmation. Host APK installed in place over ADB with the existing journal and 1.52 GB India map retained. Full Java-to-signed-APK compiler smoke test passed on the build computer, including alignment, signature and unchanged resources/native libraries. On-phone compiler and Android Keystore SSH publishing still require validation. GOD’s first compiler requires Android 15 or later.
